02 Operasi lanjutan matriks

A. Perkalian matriks

Am×n Bn×p = Cm×p

Jumlah kolom matriks pertama harus sama dengan jumlah baris matriks kedua. Ordo hasil diperoleh dari baris matriks pertama × kolom matriks kedua.

[ 2  1 ; 3  2 ] [ 1  4 ; 2  1 ] = [ 4  9 ; 7  14 ]

B. Transpose

A = [ 4  2 ; 1  3 ]   ⇒   AT = [ 4  1 ; 2  3 ]

Transpose menukar baris menjadi kolom. Jika A berordo m × n, maka AT berordo n × m.

C. Perkalian skalar

2A = 2[ 4  2 ; 1  3 ] = [ 8  4 ; 2  6 ]
Perhatian: perkalian matriks tidak dilakukan dengan mengalikan elemen yang posisinya sama. Gunakan perkalian baris-kolom.

04 Determinan matriks

Determinan adalah nilai skalar yang dapat dihitung dari matriks persegi. Determinan digunakan, antara lain, untuk menguji apakah suatu matriks memiliki invers.

A. Determinan 2 × 2

A = [ a  b ; c  d ]
det(A) = ad − bc

Contoh:

A = [ 4  2 ; 1  3 ]
det(A) = (4 × 3) − (2 × 1) = 12 − 2 = 10

B. Determinan 3 × 3 (ekspansi kofaktor baris pertama)

A = [ a  b  c ; d  e  f ; g  h  i ]
det(A) = a(ei − fh) − b(di − fg) + c(dh − eg)

Contoh:

A = [ 1  2  0 ; 0  1  1 ; 2  0  1 ]
det(A) = 1(1×1 − 1×0) − 2(0×1 − 1×2) + 0 = 1 + 4 = 5
Syarat invertibilitas: matriks persegi A memiliki invers jika dan hanya jika det(A) ≠ 0.

05 Invers matriks

Invers matriks A ditulis A−1. Invers memenuhi:

AA−1 = A−1A = I

Untuk matriks 2 × 2:

A = [ a  b ; c  d ]
A−1 = 1/(ad − bc) [ d  −b ; −c  a ]

Rumus berlaku jika ad − bc ≠ 0.

Contoh perhitungan

A = [ 4  2 ; 1  3 ],   det(A) = 10
A−1 = 1/10 [ 3  −2 ; −1  4 ]
= [ 0,3  −0,2 ; −0,1  0,4 ]

Invers matriks 3 × 3

Dapat diperoleh melalui metode adjoin:

A−1 = adj(A) / det(A),   det(A) ≠ 0

atau dengan eliminasi Gauss–Jordan:

[ A | I ]   →   [ I | A−1 ]
Matriks yang determinannya nol tidak memiliki invers. Jangan membagi dengan determinan nol.

06 Determinan dan invers terhadap SPL

Sistem persamaan linear dapat ditulis dalam bentuk perkalian matriks:

AX = B
MatriksIsiOrdo
AMatriks koefisien variabel2 × 2

Studi kasus: menentukan jumlah dua jenis komponen

Sebuah unit produksi membuat komponen X dan Y. Dua persamaan kebutuhan proses menghasilkan model:

4x + 2y = 18
x + 3y = 11

Susun ke bentuk matriks:

[ 4  2 ; 1  3 ]2×2 [ x ; y ]2×1 = [ 18 ; 11 ]2×1

Langkah penyelesaian menggunakan invers

1
Identifikasi matriks koefisien A, vektor variabel X, dan vektor konstanta B.
2
Hitung determinan A: det(A) = (4 × 3) − (2 × 1) = 10. Karena 10 ≠ 0, invers A ada.
3
Tentukan invers: A−1 = 1/10 [ 3 −2 ; −1 4 ].
4
Kalikan kedua sisi dengan A−1: A−1AX = A−1B.
5
Gunakan A−1A = I, sehingga X = A−1B.
6
Hitung hasil perkalian matriks dan verifikasi ke persamaan awal.
X = 1/10 [ 3  −2 ; −1  4 ] [ 18 ; 11 ]
X = 1/10 [ (3×18) − (2×11) ; (−1×18) + (4×11) ]
X = 1/10 [ 32 ; 26 ] = [ 3,2 ; 2,6 ]
Hasil: x = 3,2 dan y = 2,6.

Verifikasi

Persamaan 1: 4(3,2) + 2(2,6) = 12,8 + 5,2 = 18 ✓
Persamaan 2: 3,2 + 3(2,6) = 3,2 + 7,8 = 11 ✓

Kedua persamaan terpenuhi, sehingga solusi benar.
