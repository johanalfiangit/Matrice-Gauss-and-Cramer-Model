01 Tujuan dan dasar matematis

Metode Cramer

Menyelesaikan SPL persegi dengan determinan. Untuk setiap variabel, ganti kolom koefisien variabel tersebut dengan vektor konstanta, lalu bagi determinan penggantinya dengan determinan utama.

Eliminasi Gauss

Menggunakan operasi baris elementer untuk mengubah matriks augmented ke bentuk eselon baris, kemudian menyelesaikan variabel dengan substitusi balik.

AX = B   A berordo n × n; X dan B berordo n × 1
Aturan ordo: An×n Xn×1 = Bn×1. Urutan selalu jumlah baris × jumlah kolom.
Syarat Cramer: det(A) ≠ 0 untuk memperoleh solusi tunggal. Jika det(A) = 0, Cramer tidak menentukan apakah sistem tidak konsisten atau memiliki tak hingga solusi; eliminasi Gauss dapat mengklasifikasikannya.

05 Penyelesaian metode Cramer

Untuk sistem AX = B, jika D = det(A) ≠ 0:

xi = Di / D

Di adalah determinan matriks A setelah kolom ke-i diganti dengan B.

06 Eliminasi Gauss dengan OBE

Operasi yang diperbolehkan:

  • Ri ↔ Rj (menukar baris)
  • Ri → kRi, k ≠ 0 (mengalikan baris)
  • Ri → Ri + kRj (menambah kelipatan baris)

Simulator memakai pemilihan pivot parsial: memilih elemen dengan nilai absolut terbesar pada kolom pivot untuk mengurangi risiko pembagian oleh angka sangat kecil.

07 Verifikasi dan interpretasi hasil

Interpretasi manufaktur: nilai solusi harus ditafsirkan sesuai satuan dan makna variabel. Nilai pecahan atau negatif bisa sah secara aljabar, tetapi belum tentu layak secara fisik untuk jumlah unit, operator, atau lot. Model operasional dapat memerlukan kendala nonnegativitas, bilangan bulat, kapasitas, dan permintaan.

08 Panduan klasifikasi sistem

Solusi tunggal

Setiap variabel mempunyai satu nilai. Untuk matriks persegi, det(A) ≠ 0.

Tidak ada solusi

Eliminasi menghasilkan baris [0 0 … 0 | k], k ≠ 0. Persamaan bertentangan.

Tak hingga solusi

Sistem konsisten tetapi memiliki variabel bebas; terdapat baris nol dan rank lebih kecil daripada jumlah variabel.

Pivot nol

Tukar baris untuk mencari pivot bukan nol. Jika tidak tersedia, kolom tersebut dapat menjadi variabel bebas.
